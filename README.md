# Gnomintosh-Sequoia

A theme configuration to make your GNOME desktop look like macOS 15 Sequoia.

## Features
* **Sequoia Style:** Light and dark shell themes with matching window borders.
* **Wallpapers:** Original macOS Sequoia wallpapers (including dynamic time-of-day shifting).
* **Fonts & Icons:** San Francisco Pro system fonts and WhiteSur icon pack.
* **Layout:** Top menu bar configuration and a bottom application dock.

## How to install?
Install the extension from the "Extension" folder, download it. Then download the config from the "dconf" folder. and place it in your home directory. Enter the command: dconf load /org/gnome/shell/extensions/ < Gnomintosh_extensions.conf
then download the wallpaper
Then open the "logo menu" extension settings and download the logo of your choice from the "logo" folder and place it in the logos
then download the icons and theme below in "Credits".
