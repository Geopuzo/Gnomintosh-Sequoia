# Gnomintosh_Sequoia

A theme configuration to make your GNOME desktop look like macOS 15 Sequoia.

## Features
* **Sequoia Style:** Light and dark shell themes with matching window borders.
* **Wallpapers:** Original macOS Sequoia wallpapers (including dynamic time-of-day shifting).
* **Fonts & Icons:** San Francisco Pro system fonts and WhiteSur icon pack.
* **Layout:** Top menu bar configuration and a bottom application dock.
